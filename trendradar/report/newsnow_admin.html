来源顺序

一份顺序同时驱动顶部来源按钮与卡片模块的排列，两者始终一致。 直接拖动行即可排序，也可用行尾按钮 ⇱ 置顶 / ▲ 上移 / ▼ 下移 / ⇲ 置底。
访客若自己拖过顺序，本地优先；需要在「全局默认值 → 来源排序」勾选锁定后，这份顺序才会强制对所有人生效。

来源启用

取消勾选的来源会从页面彻底隐藏——顶部来源按钮、卡片模块、来源目录都不再出现。 顺序里被停用的来源会保留位置，重新启用后回到原位。

接口与文件

未设置环境变量时，口令自动生成并保存在 state/admin_token.txt，可用 docker exec trendradar cat /app/state/admin_token.txt 查看。
